# canteen-sniper 机关食堂抢位模拟器

国庆 7 天,你是一名游客,目标:抢到机关食堂的午餐名额。
每天 10:00 放号 30 个名额,34 个 AI 抢位手(手速/网速/运气三维)和你同场竞技。

## 热点来源声明

灵感来自 2026 年国庆真实热点:据央视《新闻周刊》报道,今年国庆假期
**不少于 70 个城市开放了机关食堂或停车场**给游客,山西长治机关食堂推出
6 元自助早餐,安徽淮南机关食堂开放首日名额就被**一抢而空**。
报道:中国旅游报《国庆假期,游客体验"升级版"》
(https://news.sina.cn/znl/2026-10-04/detail-initzrfm5566072.d.html)。

本游戏只借用了"抢名额"这个概念做善意玩梗,全部规则、数值、文案均为原创,
与任何真实单位、真实预约系统无关。

## 玩法

三种蹲点策略,各有利弊:

| 策略 | 抢位修正 | 心态消耗 | 说明 |
|---|---|---|---|
| 提前蹲点 | +25 | -25 | 提前 5 分钟蹲守,命中率高但费心态 |
| 掐点整抢 | +10 | -5 | 10:00:00 准时开抢,中庸之选 |
| 随缘佛系 | -10 | +20 | 命中率低,但能回心态 |

心态值归零则当天强制摆烂(不抢号,只回血)。

每日随机事件:

- 【局长大气】食堂临时加 10 个名额
- 【网络卡顿】你的请求一直在转圈圈,当天抢位分 -20
- 【亲情召唤】被家人喊去下馆子,错过放号(心态 +10)
- 【大爷秘籍】隔壁桌大爷传授抢位秘籍,抢位分永久 +8
- 风平浪静

7 天抢到的午餐数决定称号:

- 7 顿:**荣誉市民**(彩蛋:集齐 7 顿解锁)
- 5-6 顿:干饭王者
- 3-4 顿:食堂编外人员
- 1-2 顿:旅游特种兵
- 0 顿:白跑一趟

## 运行

需要 Python 3.10+,纯标准库,零依赖。

```bash
# 交互游玩
python3 -m canteen_sniper

# 自动演示 10 局(固定种子,可复现)
python3 -m canteen_sniper --auto --games 10 --seed 42

# 打印每日战报
python3 -m canteen_sniper --auto --games 1 --seed 7 --verbose
```

## 诚实局限

- 数值(策略加成、AI 属性、事件概率)为拍脑袋调参,平衡性未经大规模仿真;
  "荣誉市民"(7 顿全中)在自动演示中很难出现,是刻意设计的稀有彩蛋。
- AI 抢位手是固定三维属性 + 均匀噪声,没有真正的"抢号策略"演化。
- 倒计时/整点抢的紧张感靠文字描述,无图形界面、无音效、无存档。
- 事件纯随机触发,没有基于真实客流数据的模型。
- 交互模式依赖 tty;Windows 终端中文显示取决于系统编码设置。
